# Wireless-Fencing-Scoring-System
Wireless fencing scoring system using ESP-32 and ESP-NOW
The system is split into two:
Wired code is in the fencer weapon zip file while the wireless code is in the wireless weapon 
- wired & wireless
- Wired: epee with two inputs since I have only one epee weapon, the other input is used with a button switch
- Wired: foil
- Wireless --- system is split into two(transmitter and receiver)
- Transmitter is equivalent to weapon while receiver is equivalent to the scoring box/apparatus
